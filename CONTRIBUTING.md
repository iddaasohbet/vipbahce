# Katkıda Bulunma Rehberi

Kış Bahçesi projesine katkıda bulunmak istediğiniz için teşekkürler! 🎉

## 🚀 Başlamadan Önce

1. Projeyi fork edin
2. Yeni bir branch oluşturun: `git checkout -b feature/yeni-ozellik`
3. Değişikliklerinizi yapın
4. Commit edin: `git commit -m 'Yeni özellik: Açıklama'`
5. Branch'inizi push edin: `git push origin feature/yeni-ozellik`
6. Pull Request açın

## 📝 Kod Standartları

- TypeScript kullanın
- ESLint kurallarına uyun
- Anlamlı commit mesajları yazın
- Responsive tasarıma dikkat edin
- Component'leri modüler tutun

## 🧪 Test

Değişikliklerinizi push etmeden önce:

```bash
npm run build
npm run lint
```

## 💡 Öneriler

- Büyük değişiklikler için önce issue açın
- Kodunuzu temiz ve okunabilir tutun
- Yorum satırları ekleyin (gerektiğinde)
- Performance'ı göz önünde bulundurun

Teşekkürler! ❤️
